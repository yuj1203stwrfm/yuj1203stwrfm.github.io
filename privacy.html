プライバシーポリシー

氷山ラボ アップロードツール（以下「このツール」）の、Google アカウントのデータの扱いについて書きます。最終更新: 2026年10月23日

使う人

このツールを使うのは、YouTube チャンネル「氷山ラボ」（@hyozanlab）の運営者だけです。ほかの人には提供していません。

使う権限と、その目的

  • youtube.upload: 作った動画を、自分のチャンネルに非公開でアップロードするため
  • youtube.readonly: 自分のチャンネルと、アップロードした動画を確かめるため
  • yt-analytics.readonly・yt-analytics-monetary.readonly: 自分のチャンネルの再生回数・視聴時間・収益の数字を読み、動画の作り方を見直すため

これ以外の目的には使いません。

保存するもの・しないもの

  • アクセスのための鍵（リフレッシュトークン）は、運営者の GitHub リポジトリの暗号化された保管場所（GitHub Actions の Secrets）にだけ置きます。
  • 読みとった数字は、自分のチャンネルの記録として、運営者の非公開のリポジトリに保存します。
  • ほかの人の個人情報は集めません。

人に渡すこと

Google から受けとったデータを、第三者に売ったり渡したりしません。広告にも使いません。このツールの Google ユーザーデータの使い方は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

やめるとき

Google アカウントのサードパーティのアクセスの設定から、いつでもこのツールのアクセスを取り消せます。取り消すと、鍵は使えなくなります。

Privacy Policy (English)

“Hyozan Lab Upload Tool” is used only by the owner of the YouTube channel Hyozan Lab (@hyozanlab). It requests youtube.upload (to upload the owner's videos to the owner's own channel as private videos), youtube.readonly (to verify the owner's channel and uploads), and yt-analytics.readonly / yt-analytics-monetary.readonly (to read the owner's own channel metrics to improve future videos). The refresh token is stored only in the owner's encrypted GitHub Actions Secrets; channel metrics are stored in the owner's private repository. No data is sold or shared with third parties or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at https://myaccount.google.com/permissions. Contact: via GitHub @yuj1203stwrfm. Last updated: October 23, 2026.
